Flight Delay ML Analysis — Resumo Didático

O que esse projeto faz: Usa dados de 5,8 milhões de voos nos EUA (ano de 2015) para tentar responder três perguntas:

  1. Dá pra prever se um voo vai atrasar?
  2. Se vai atrasar, dá pra saber por quanto tempo?
  3. Existem grupos naturais de aeroportos que se comportam de forma parecida?

1. Carregamento dos Dados

O que acontece aqui: Lemos 3 arquivos — um com dados de voos (592 MB, o principal), um com nomes de companhias aéreas e um com informações de aeroportos. Como o arquivo de voos é muito grande, usamos tipos de dados menores (ex: int8 em vez de int64) pra economizar memória.

2. Preparação dos Dados

2.1 Junção das tabelas

O que acontece aqui: A tabela de voos só tem códigos (ex: "AA" pra American Airlines, "ATL" pra Atlanta). Juntamos com as outras tabelas pra ter os nomes completos. É como um PROCV do Excel — cruzamos pelo código e trazemos o nome. 
# Junta voos + companhias + aeroportos (3 left joins)
df_merged = df_flights.merge(df_airlines, ...)   # adiciona nome da companhia
                      .merge(df_airports, ...)   # adiciona cidade/estado de origem
                      .merge(df_airports, ...)   # adiciona cidade/estado de destino
# Resultado: 5.819.079 linhas x 36 colunas

2.2 Dados faltantes

Problema encontrado: Algumas colunas têm mais de 80% dos valores vazios (ex: WEATHER_DELAY, AIRLINE_DELAY). Isso é normal — essas colunas só são preenchidas quando o voo realmente atrasa. Voos pontuais ficam em branco.

Solução: Removemos apenas as linhas onde as 4 colunas essenciais estão vazias (ARRIVAL_DELAY, DEPARTURE_DELAY, SCHEDULED_TIME, DISTANCE). Perdemos só 1,8% dos dados.

2.3 Criação de novas colunas

O que acontece aqui: Criamos colunas novas a partir das que já existem pra facilitar a análise. Isso se chama "Feature Engineering" — é transformar dados brutos em informações mais úteis pro modelo. 
# Novas colunas criadas:
df['HOUR_OF_DAY'] = ...  # Hora do voo (0-23), tirada do horário programado
df['IS_WEEKEND']  = ...  # 1 se sábado/domingo, 0 se dia útil
df['IS_DELAYED']  = ...  # 1 se atrasou 15 min ou mais, 0 se não (nosso "alvo")
df['ROUTE']       = ...  # Rota (ex: "ATL-LAX")
Taxa de atraso: 18,6% dos voos atrasaram 15 minutos ou mais. Dataset final: 5.714.008 linhas x 40 colunas

3. Exploração dos Dados (EDA)

O que acontece aqui: Antes de criar modelos, exploramos os dados pra entender os padrões. Calculamos médias, criamos gráficos e procuramos tendências. É como conhecer o terreno antes de construir.

Números gerais

Atraso médio de chegada: 4,4 min (a maioria chega no horário ou adiantado) Mediana do atraso: -5,0 min (metade dos voos chega 5 min antes!) Maior atraso registrado: 1.971 min (~33 horas)

Padrões descobertos

Quando os voos mais atrasam?
  • Hora do dia: Atrasos aumentam ao longo do dia. Pior horário: 18h–21h. Melhor: 5h–7h. Isso acontece por efeito cascata — um atraso de manhã vai se propagando pros voos seguintes.
  • Dia da semana: Quinta e sexta são os piores dias. Sábado é o melhor.
  • Mês: Junho–julho (verão americano) e dezembro–janeiro (inverno) são os piores. Setembro–outubro são os melhores.
Quais aeroportos e companhias mais atrasam?
  • Aeroportos: Os que mais atrasam são pequenos e regionais (PBG: 32%, MMH: 30%, ASE: 30%).
  • Companhias: Spirit e Frontier lideram os atrasos. Alaska Airlines e Hawaiian são as mais pontuais.
Correlações importantes: Se um voo sai atrasado, quase certamente chega atrasado (correlação de 0,945 entre atraso de partida e de chegada). Distância e tempo de voo são praticamente a mesma informação (correlação de 0,986).

4. Classificação: "O voo vai atrasar?"

O que acontece aqui: Treinamos o computador pra responder SIM ou NÃO — o voo vai atrasar 15 minutos ou mais? Usamos informações disponíveis antes do voo (mês, dia, hora, companhia, aeroporto, distância). Testamos dois algoritmos:

Logistic Regression — o mais simples. Traça uma "linha reta" pra separar atrasados de não atrasados.
Random Forest — mais sofisticado. Cria 100 "árvores de decisão" (tipo fluxogramas de perguntas) e combina as respostas de todas pra decidir.
Pense assim: Logistic Regression é como um médico que usa uma única regra simples pra dar o diagnóstico. Random Forest é como um conselho de 100 médicos — cada um analisa de um ângulo diferente e eles votam juntos.

# Dois modelos treinados

ModeloAccuracyPrecisionRecallF1

Random Forest81,4%68%0,3%0,6%
O que essas métricas querem dizer:
  • Accuracy (81,4%): Parece bom, mas é enganoso. Como 81,4% dos voos NÃO atrasam, um modelo que sempre diz "não vai atrasar" já acerta 81,4%. É exatamente o que a Logistic Regression faz.
  • Precision (68%): Quando o Random Forest diz "vai atrasar", ele acerta 68% das vezes.
  • Recall (0,3%): Mas ele só consegue identificar 0,3% dos voos que realmente atrasam — quase nenhum.
Conclusão: Os modelos não conseguem prever atrasos de forma útil. O motivo principal: as informações que temos (mês, hora, companhia) não são suficientes. Atrasos dependem muito de clima, tráfego aéreo e problemas operacionais — dados que não estão no dataset.

5. Regressão: "Quanto tempo vai atrasar?"

O que acontece aqui: Pra os voos que já sabemos que atrasaram, tentamos prever quantos minutos de atraso. Usamos só os 2 milhões de voos atrasados. Testamos dois algoritmos:

Linear Regression — tenta achar uma fórmula (uma reta) que relacione as informações ao atraso.
Random Forest Regressor — mesma ideia das 100 árvores, mas em vez de votar SIM/NÃO, cada árvore estima um número de minutos e o resultado final é a média de todas. 
# Só voos atrasados (ARRIVAL_DELAY > 0)
# 2.086.896 voos | Média de atraso: 33 min | Mediana: 15 min | Máximo: 1.627 min

model_lr  = LinearRegression()          # fórmula linear
model_rfr = RandomForestRegressor()     # conjunto de árvores

Resultados

ModeloMAERMSER²
Linear Regression30,7 min52,2 min0,01 (1%)
Random Forest30,0 min51,6 min0,03 (3%)
O que essas métricas querem dizer:
  • MAE (30 min): Na média, o modelo erra por 30 minutos. Pra atrasos com mediana de 15 min, é muito erro.
  • RMSE (52 min): Parecido com o MAE, mas dá mais peso pros erros grandes. Quanto menor, melhor.
  • R² (3%): O modelo só explica 3% da variação dos atrasos. Os outros 97% dependem de coisas que não temos no dataset.
Conclusão: Prever a duração do atraso é ainda mais difícil do que prever se vai atrasar. Sem dados de clima e informações operacionais, os modelos são praticamente aleatórios.

7. Visualização em 2D (PCA)

O que acontece aqui: Cada aeroporto tem 6 características — impossível de ver num gráfico. O PCA comprime essas 6 dimensões em apenas 2, guardando o máximo de informação possível. É como tirar uma foto de um objeto 3D — você perde um pouco de detalhe, mas consegue ver a forma geral.
Pense assim: imagine que cada aeroporto é descrito por 6 notas (volume, atraso, distância...). O PCA combina essas notas em 2 "super-notas" que resumem a maior parte da informação. A primeira super-nota (PC1) captura principalmente o tamanho do aeroporto. A segunda (PC2) captura o tipo de rotas e cancelamentos. 
# Reduz de 6 dimensões pra 2
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)
Informação preservada: PC1: 54,8% (tamanho e volume do aeroporto) PC2: 22,6% (distância das rotas e cancelamentos) Total: 77,4% da informação original mantida em 2D Outliers: ATL, ORD, DFW, LAX (os maiores hubs do país)
O que o gráfico mostra: Os grandes hubs (cluster 3) ficam isolados no canto do gráfico, bem separados dos demais. A maioria dos aeroportos regionais se concentra perto do centro. Isso confirma que o volume de operações é o que mais diferencia os aeroportos entre si.

8. Conclusões

O que aprendemos

PerguntaResposta
Dá pra prever se um voo vai atrasar?Não de forma útil — com os dados disponíveis, os modelos quase não detectam atrasos (recall ~0%)
Dá pra prever quanto tempo vai atrasar?Não com precisão — erro médio de 30 min, modelo explica só 3% da variação
Existem grupos de aeroportos?Sim! — 6 perfis claros, desde grandes hubs até pequenos aeroportos com problemas crônicos

Por que os modelos preditivos não funcionaram bem

O principal motivo é a falta de dados externos. Atrasos de voo dependem muito de:
  • Clima — tempestades, neve, neblina (não está no dataset)
  • Tráfego aéreo — congestionamento no espaço aéreo (não está no dataset)
  • Problemas operacionais — manutenção, falta de tripulação (não está no dataset)
Só com mês, hora, companhia e aeroporto, não tem informação suficiente pra prever atrasos.
