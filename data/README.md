# Data Directory

Coloque os arquivos do dataset aqui antes de executar os notebooks.

## Arquivos Necessários

| Arquivo        | Tamanho  | Descrição                          |
|----------------|----------|------------------------------------|
| airlines.csv   | ~359 B   | Códigos e nomes das companhias     |
| airports.csv   | ~24 KB   | Informações dos aeroportos dos EUA |
| flights.csv    | ~592 MB  | Dados históricos de voos (principal) |

## Como Baixar

1. Acesse o dataset no Kaggle: https://www.kaggle.com/datasets/usdot/flight-delays
2. Clique em **Download** (é necessário ter uma conta Kaggle)
3. Extraia o arquivo ZIP baixado
4. Copie os 3 arquivos CSV (`airlines.csv`, `airports.csv`, `flights.csv`) para este diretório (`data/`)

> **Nota:** O arquivo `flights.csv` tem ~592 MB. Certifique-se de ter espaço em disco suficiente.
